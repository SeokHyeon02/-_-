# MyLink 와이어프레임

5주차 PDF p.31의 **상단 프로필 이미지/이름/소개 + 하단 링크 목록** 구성을 유지합니다.

## 공개 페이지 `/[username]`

```text
┌───────────────────────────────────┐
│ MyLink                    홈으로  │
├───────────────────────────────────┤
│          [프로필 아바타]          │
│            사용자 이름            │
│            @username              │
│           소개글 1~2줄           │
│                                   │
│  ┌─────────────────────────────┐  │
│  │ [아이콘]  인스타그램     ↗ │  │
│  └─────────────────────────────┘  │
│  ┌─────────────────────────────┐  │
│  │ [아이콘]  유튜브         ↗ │  │
│  └─────────────────────────────┘  │
│  ┌─────────────────────────────┐  │
│  │ [아이콘]  블로그         ↗ │  │
│  └─────────────────────────────┘  │
│         made with mylink         │
└───────────────────────────────────┘
```

## 마이페이지 `/mypage`

```text
┌───────────────────────────────┬──────────────────────────┐
│ 프로필 편집                    │ 공개 페이지 미리보기      │
│  username                     │ [아바타]                 │
│  displayName                  │ 이름 / @username         │
│  bio                          │ 소개글                   │
│ [프로필 저장]                  │ ┌──────────────────────┐ │
├───────────────────────────────┤ │ [아이콘] 링크 이름 ↗ │ │
│ 링크 관리                     │ └──────────────────────┘ │
│  제목                         │ ┌──────────────────────┐ │
│  URL                          │ │ [아이콘] 링크 이름 ↗ │ │
│ [링크 추가]                   │ └──────────────────────┘ │
│                               │                          │
│ 링크 목록                     │ [개인 URL][복사][열기]    │
│ [링크]       [수정] [삭제]    │                          │
│  └ 수정 클릭 시 같은 줄 편집  │                          │
└───────────────────────────────┴──────────────────────────┘
```

**모바일 360px 이하:** 마이페이지 편집 영역이 먼저 보이고, 미리보기는 아래로 배치합니다.
